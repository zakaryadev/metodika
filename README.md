# Методик платформа — профилактика правонарушений среди несовершеннолетних

Платформа методических материалов по теме:

> **Вояга етмаган ҳуқуқбузарлар билан олиб бориладиган профилактик ишлар самарадорлигини оширишнинг педагогик шарт-шароитлари**

Аналог [lingvometodika.uz](https://lingvometodika.uz), адаптированный под педагогику профилактики.

**Игровые движки:** тест, верно/неверно, парная память, сопоставление, флеш-карты,

Кроссворд и поиск слов **генерируются алгоритмически** из списка слов — при смене
алфавита сетка перестраивается заново.

## Кириллица ↔ латиница

Весь контент хранится **только в узбекской кириллице**. Латиница генерируется
автоматически транслитератором `src/lib/translit.ts` — дублировать тексты не нужно.

Переключатель `ЎЗ / OʻZ` в шапке. Выбор сохраняется в браузере.

```
Вояга етмаган ҳуқуқбузарлар  →  Voyaga yetmagan huquqbuzarlar
Ўзбекистон Республикаси      →  Oʻzbekiston Respublikasi
ЁШЛАР ВА ҲУҚУҚ               →  YOSHLAR VA HUQUQ
```

Если какое-то слово транслитерируется неверно, добавьте его в `EXCEPTIONS`
в `src/lib/translit.ts`.

## Сборка и деплой

```bash
npm run build
```

Собирается статический сайт в папку `out/` (81 страница). Его можно положить
на **Vercel, Netlify, GitHub Pages** или обычный хостинг — сервер Node не нужен.

Локальный просмотр собранной версии:

```bash
npm run preview
```

> `npm run build` после сборки запускает `scripts/flatten-segments.mjs`.
> Next.js 16 записывает файлы предзагрузки навигации во вложенные папки,
> а браузер запрашивает их плоским именем — скрипт делает копии с нужными
> именами. Без него в консоли будут 404 на префетч-запросах.

### Vercel
Подключите репозиторий — настройки определятся автоматически.

### Netlify
Build command: `npm run build`, publish directory: `out`.

### Обычный хостинг
Загрузите содержимое `out/` в корень сайта по FTP.

## Как редактировать контент

Весь контент — обычные TypeScript-файлы в `src/content/`. Редактор подскажет
структуру, а `npm run build` не соберётся при ошибке — это защита от опечаток.

| Файл | Что менять |
|---|---|
| `site.ts` | Название, домен, заголовок на главной, список разделов |
| `author.ts` | **Данные автора — заполните своими** |
| `categories.ts` | Категории (рубрики) материалов |
| `presentations.ts` | Презентации и их слайды |
| `methods.ts` | Методы: цель, этапы, материалы, результат |
| `games.ts` | Данные для игр |
| `videos.ts` | Видео — впишите `youtubeId` |
| `tasks.ts` | Ситуационные задания |
| `tests.ts` | Тесты |
| `diagnostics.ts` | Опросники: шкала, вопросы, диапазоны баллов |
| `legal.ts` | Нормативные документы |

### Добавить презентацию

```ts
{
  slug: "yangi-mavzu",              // латиницей, попадёт в адрес страницы
  title: "Янги мавзу",
  category: "profilaktika",          // id из categories.ts
  description: "Қисқача тавсиф.",
  views: 0,
  slides: [
    {
      title: "Биринчи слайд",
      bullets: ["Биринчи фикр", "Иккинчи фикр"],
      note: "Ихтиёрий изоҳ",         // необязательно
    },
  ],
}
```

### Добавить видео

Из ссылки `https://www.youtube.com/watch?v=ABC123` возьмите часть после `v=`:

```ts
youtubeId: "ABC123",
```

Пока поле пустое, на странице показывается заглушка «видео скоро будет».

### Добавить опросник в диагностику

`bands` — диапазоны баллов. Они должны покрывать всё от `0` до
`количество вопросов × максимальный балл шкалы` без разрывов:

```ts
scale: [
  { label: "Ҳеч қачон", value: 0 },
  { label: "Баъзан", value: 1 },
  { label: "Доимо", value: 2 },
],
questions: ["Биринчи кўрсаткич", "Иккинчи кўрсаткич"],
bands: [
  { min: 0, max: 1, level: "Паст хавф", tone: "low",  advice: "Тавсия…" },
  { min: 2, max: 4, level: "Юқори хавф", tone: "high", advice: "Тавсия…" },
],
```

`tone`: `low` — зелёный, `mid` — жёлтый, `high` — красный.

## Счётчик просмотров

На карточках и страницах материалов показывается число просмотров (👁), как в
оригинале. Счётчик общий для всех посетителей — он живёт в бесплатной базе
Supabase, сайт при этом остаётся полностью статическим.

**Пока ключи не заданы, счётчик просто не показывается** — сайт работает как
обычно, ошибок нет.

### Подключение

**Уже настроено и работает.** Проект Supabase подключён, схема применена,
ключи лежат в `.env` (этот файл в репозиторий не попадает).

Если понадобится поднять счётчик на другом проекте Supabase:

1. Создайте проект на [supabase.com](https://supabase.com).
2. В **SQL Editor** выполните [`supabase/schema.sql`](supabase/schema.sql).
3. В **Project Settings → API** скопируйте `Project URL` и **Publishable key**
   (`sb_publishable_…`; в старых проектах — `anon public`).
4. Скопируйте `.env.example` в `.env`, вставьте значения и пересоберите:

```bash
cp .env.example .env
```

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

> Ключи `NEXT_PUBLIC_*` подставляются **во время сборки**, поэтому `.env` надо
> заполнить до `npm run build`. После смены ключей сборку нужно повторить.

### Как это устроено

- Просмотр засчитывается один раз за сессию браузера — перезагрузка страницы
  счётчик не накручивает.
- Писать в таблицу напрямую нельзя: увеличение идёт только через функцию
  `increment_view`, включён Row Level Security. Публичный ключ может лишь
  читать числа и вызывать эту функцию.
- Если база недоступна или таблица ещё не создана, счётчики просто не
  показываются — нулей вместо чисел не будет.
- Для игр показывается, сколько раз в них играли.
- Начальные числа (если не хотите стартовать с нуля) можно проставить SQL-ом —
  пример есть в конце `supabase/schema.sql`.

## Важно проверить перед публикацией

- **`src/content/author.ts`** — там сейчас заглушки, впишите свои данные.
- **`src/content/legal.ts`** — у восьми документов из девяти **намеренно нет
  номера, даты и ссылки**. Я не смог подтвердить их на lex.uz, а неверная
  ссылка на закон хуже её отсутствия, поэтому реквизиты убраны. На сайте такие
  документы помечены «реквизитлар аниқланмаган», содержание при этом осталось.

  Как заполнить: найдите документ на lex.uz, скопируйте номер и дату из
  заголовка страницы (например `ЎРҚ-996-сон 14.11.2024`), ссылку возьмите из
  адресной строки, затем удалите строку `needsCitation: true`. Подтверждён и
  заполнен только закон ЎРҚ-996 от 14.11.2024.
- **`src/content/site.ts`** — поле `domain` (сейчас `profilaktika.uz`).
- Фото автора: положите файл в `public/` и подключите на странице `/muallif`.

## Приватность

Сайт статический, без базы данных и без аккаунтов. Ответы на опросники и
тексты в полях заданий **не покидают браузер** и никуда не отправляются.
Выбор алфавита и темы хранятся в `localStorage` этого браузера.

## Градиенты и орнамент

Визуальная система повторяет оригинал: цветные поверхности — это градиенты
`to bottom right`, поверх них лежит слой национального орнамента.

### Градиенты

Все заданы токенами в [`src/app/globals.css`](src/app/globals.css) и одинаковы
в светлой и тёмной теме — они всегда под белым текстом:

| Токен | Где | Цвета |
|---|---|---|
| `--grad-hero` | hero на главной и у автора | `#173cb6 → #1b5ef5 → #0ea5e9` |
| `--grad-footer` | подвал | `#19378f → #173cb6 → #0f172a` |
| `--grad-blue` | Тақдимотлар | `#3b82f6 → #22d3ee` |
| `--grad-violet` | Методлар | `#8b5cf6 → #e879f9` |
| `--grad-emerald` | Ўйинлар | `#10b981 → #2dd4bf` |
| `--grad-orange` | Видеодарслар | `#f97316 → #fbbf24` |
| `--grad-rose` | Топшириқлар | `#f43f5e → #f472b6` |
| `--grad-cyan` | Тестлар | `#0ea5e9 → #818cf8` |
| `--grad-amber` | Диагностика | `#d97706 → #facc15` |
| `--grad-indigo` | Ҳуқуқий база | `#4f46e5 → #a78bfa` |
| `--grad-brand` | карточки презентаций, логотип | `#1b5ef5 → #0ea5e9` |

Градиент раздела берётся через `accentGradient(accent)` из
[`src/components/ui.tsx`](src/components/ui.tsx), градиент игры — через
`gameKindGradient` из [`src/content/games.ts`](src/content/games.ts).

### Орнамент

Файл — `public/naqsh.png` (белый узор на прозрачном фоне). Накладывается
отдельным слоем компонентами из
[`src/components/Ornament.tsx`](src/components/Ornament.tsx):

| Место | Размер плитки | Прозрачность |
|---|---|---|
| Hero | 190px | 8% |
| Hero, большой узор справа (`OrnamentMedallion`) | 420px | 20% |
| Шапки карточек разделов | 90px | 15% |
| Шапки карточек игр | 100px | 15% |
| Шапки карточек презентаций, заголовок слайда | 110px | 10% |
| Подвал | 160px | 7% |
| Логотип, значок раздела (`OrnamentFill`) | во всю плитку | 30% |
| Рамка по краям страницы (`body::before` / `body::after`) | 72px | 9% / 13% в тёмной |

Орнамент всегда отдельный слой `absolute inset-0`, а не `background-image` на
самом блоке: цвет задаётся инлайновым сокращением `background: …`, которое
затирает `background-image`. Родителю нужен `position: relative` и
`overflow: hidden`, а тексту и значкам поверх узора — `relative`.

Рамка по краям страницы — особый случай. Это две фиксированные полосы
(`body::before` и `body::after`) шириной ровно 72px у левого и правого края
окна; плитка узора тоже 72px, поэтому один мотив точно вписывается в ширину
полосы. Узор белый и на светлом фоне был бы не виден, поэтому там он
используется как `mask-image` и окрашивается в фиксированный `#1b5ef5` —
цвет одинаков в обеих темах, меняется только прозрачность
(`--frame-opacity`). Полосы показываются от ширины окна 1440px.

Над шапкой идёт полоска `.top-bar` высотой 6px с градиентом
`#1449e1 → #327eff → #38bdf8`.

Чтобы заменить орнамент, положите свой PNG с прозрачным фоном на место
`public/naqsh.png` — код менять не нужно.

## Технологии

- Next.js 16 (App Router), React 19, TypeScript
- Tailwind CSS 4, тёмная и светлая тема
- Статический экспорт — без серверной части
- Собственный транслитератор кириллица → латиница

## Структура

```
src/
  app/          страницы и маршруты
  components/   интерфейс
    games/      16 игровых движков
  content/      ← весь контент здесь
  lib/          транслитерация, темы, генераторы кроссворда и поиска слов
scripts/        доработка статической сборки
```
